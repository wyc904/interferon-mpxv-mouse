# legacy/ 历史脚本

本目录保存首版投稿、二次调图和探索阶段的 R 脚本，**按文件内容去重**后共 133 个。目的只是保留每张图的生成过程，方便追溯；它们**不是**仓库的主流程，也不能保证直接运行。

## 怎么用

1. 先看 [`MANIFEST.tsv`](MANIFEST.tsv)：
   - `id`：本目录中的脚本编号（`001_...R`）
   - `md5`：文件内容哈希
   - `representative`：保留下来的代表版本（相对原项目根目录）
   - `all_original_paths`：所有内容相同的原始路径（`;` 分隔）
2. 找到与你要复现的图相关的脚本后，再对照 `docs/figure_map.md` 第 3 节。
3. 这些脚本里通常有旧的绝对路径（如 `D:/Desktop/...`、`D:/Desktop/Project/10-干扰素小鼠/...`），运行前必须改成当前路径；部分脚本还依赖手工整理的 Excel 或 RStudio 交互，不能无人值守跑通。

## 为什么不全放进 scripts/

主流程（`scripts/1009_pipeline/`、`scripts/3mice_pipeline/`）已经覆盖论文的主要图件，并且做了路径重构、参数集中和文档化。历史脚本里有大量同名不同版的中间稿（例如同一张 GO 图改了十几版），全部混进主目录会让复现者无从下手，因此单独归档。
