# 干扰素小鼠 MPXV 感染模型 RNA-seq 分析说明（3-1009 主流程）

生成时间：2026-10-10 ｜ 更新：2026-10-12（GO 气泡图改为每比较组 Top 5、每图合计 ≤30 条通路；热图改为每比较组 Top 8、每图 ≤48 个基因） ｜ 分析环境：R 4.4.0 + DESeq2 1.44.0 + clusterProfiler（脚本见 `scripts/1009_pipeline/`）

## 1. 数据与实验设计

- **源数据**：`data/raw/MPXV_RB_counts_gene.txt`（featureCounts v2.0.3，`-p -B -C -t exon -g gene_name`；参考基因组 Cell Ranger refdata-gex-GRCm39-2024-A = 小鼠 GRCm39）
- **样本**：66 个 = BALB/c 38 + AG129 28；每只小鼠取**肺（Lung）**与**脾（Spleen）**
- **分组**（本批次四组）：
  - **G1**：未感染（uninfected）
  - **G2**：感染（infected）
  - **G3**：Tecovirimat 治疗组
  - **G4**：DMSO 溶剂对照（vehicle）
- 样本编号 ↔ 测序名 ↔ 计数矩阵列名对照表：`metadata/sample_sheet.csv`（构建与核对见 `metadata/sample_sheet_notes.txt`；对照表与矩阵表头 66/66 完全一致）

各数据集样本数：

| 数据集 | G1 | G2 | G3 | G4 | 合计 |
|---|---|---|---|---|---|
| BALB/c — 肺 | 5 | 5 | 5 | 5 | 20 |
| BALB/c — 脾 | 5 | 5 | 4 | 4 | 18 |
| AG129 — 肺 | 3 | 4 | 4 | 4 | 15 |
| AG129 — 脾 | 3 | 4 | 2 | 4 | 13 |

缺失样本：BALB/c G3 脾-1、G4 脾-5；AG129 G1 肺-1/脾-2、G3 脾-1/脾-3。

## 2. 分析流程（每套数据集独立分析）

| 步骤 | 方法 | 脚本 |
|---|---|---|
| 差异分析 | DESeq2（design `~ group`，G1 为参照）；低表达过滤：count≥10 的样本数 ≥ 最小分组样本数；差异阈值 **padj < 0.05 且 \|log2FC\| > 1** | `01_deseq2.R` |
| PCA | VST 归一化，取方差最大 500 基因 | `02_basic_figures.R` |
| DEG 数量柱状图 | 6 个比较 × 上/下调 | 同上 |
| 韦恩图 | 每个治疗组分 3 集：G2vsG1 / Gx vs G1 / Gx vs G2（All·Up·Down 三版） | 同上 |
| 火山图 | 每比较 1 图 + 2×3 网格；Top15（padj）标注；y 轴按 99.5% 分位截断 | 同上 |
| GO 富集 | clusterProfiler compareCluster + enrichGO（BP，org.Mm.eg.db，BH，p<0.05，q<0.2）；每比较组取 **Top5**（每图合计 ≤30 条）进图，上调红系 / 下调蓝系 | `03b_go_top30.R`（原 `03_go_enrichment.R`） |
| 热图 | 每比较组 Top8（padj）显著 DEG 并集（每图 ≤48 个）；VST → 行 Z-score（±3 截断）；pheatmap，列注释仅 Group | `04b_heatmap_top50.R`（原 `04_heatmap.R`） |
| 合成图 | 模板式 a–f 组合（PCA/DEG数量/韦恩×2/火山网格/GO×2） | `05_composite.R` |

**6 个比较组**：`G2vsG1`（感染效应）、`G3vsG1`、`G3vsG2`、`G4vsG1`、`G4vsG2`、`G4vsG3`。

> `G3vsG4` 是 Tecovirimat 相对 DMSO 溶剂的关键药物效应比较；`G4vsG3` 是其反向。`G4vsG2` 是溶剂对照相对感染组，不能直接当作药物效应。

## 4. 主要结果速览（显著 DEG 数量）

| 比较 | BALB/c 肺 | BALB/c 脾 | AG129 肺 | AG129 脾 |
|---|---|---|---|---|
| G2 vs G1（感染） | 691↑ / 123↓ | 153↑ / 31↓ | 1351↑ / 841↓ | 790↑ / 594↓ |
| G3 vs G1 | 109↑ / 8↓ | 72↑ / 127↓ | 225↑ / 4↓ | 259↑ / 33↓ |
| G3 vs G2 | 96↑ / 324↓ | 385↑ / 608↓ | 711↑ / 494↓ | 64↑ / 19↓ |
| G4 vs G1 | 159↑ / 127↓ | 91↑ / 34↓ | 648↑ / 38↓ | 367↑ / 16↓ |
| G4 vs G2 | 76↑ / 508↓ | 266↑ / 322↓ | 302↑ / 89↓ | 193↑ / 17↓ |
| G4 vs G3 | 10↑ / 81↓ | 0↑ / 0↓ | 7↑ / 1↓ | 1↑ / 0↓ |

要点：① 感染（G2vsG1）在 AG129（干扰素受体缺陷）中反应最强（肺 2192 个 DEG）；② G3（Tecovirimat）和 G4（DMSO 溶剂）相对感染组都有大量 DEG，其中 G4vsG2 的下调（如 BALB/c 肺 508 个）主要反映溶剂/感染相关效应，不能直接当作药物效应；③ **G3 与 G4 之间差异很小（G4vsG3 几乎无 DEG）**，提示在该批次/剂量下 Tecovirimat 对肺、脾转录组的整体影响有限；这不等于病毒载量或病理无差异，需结合湿实验判断。

## 5. 注意事项

- **AG129 G3 脾仅 2 个样本**，统计效力有限，解读该组结果时请注意；BALB/c 脾亦各缺 1 个重复。
- GO 气泡图中通路名称超过 58 字符的做截断显示（以 “…” 结尾），完整名称见对应 `GO富集_*.xlsx`；某比较组 DEG 过少时（如 G4vsG3）该列在气泡图中自动省略（无显著通路）。
- GO 气泡图为**每比较组 Top 5（每图合计 ≤30 条）**版（`GO_Bubble_{Up,Down}_*.png/pdf`），绘图数据见 `00-汇总/GO富集_Top30_汇总.xlsx`（每组显著通路不足 5 条时少画，如 AG129 肺 G4vsG1 下调仅 1 条）；旧 Top15 版图（2026-10-10 版）未包含在本仓库；其绘图数据仍在各数据集 `GO富集_*.xlsx` 的 Plot_* 表中。
- 07-合成图内的 GO 面板沿用 Top15 版（合成图面板空间有限）；完整 Top30 图请用 05-GO富集 下的正式版。
- 热图为**每比较组 Top 8**（去重后每图 ≤48 个基因，实际 23–35 个）；原每比较组 Top50（148–188 个）版未包含在本仓库（可用 `04_heatmap.R` 重跑）。画布尺寸按内容自适应（原公式为长图设计，短图会留白）。
- 图上沿用 **G1–G4 代号**；`scripts/1009_pipeline/utils/common.R` 的 `GROUP_DESC` 已写入 **G3 = Tecovirimat、G4 = DMSO vehicle**，图例可直接显示药名。
- 火山图中 padj 为 NA 的基因（DESeq2 独立过滤剔除）不显示；y 轴按 99.5% 分位截断（个别超高显著性点压至顶端）。
- G1–G4 的生物学解读、治疗药物信息由实验方补充确认。
